# Costory Cursor Plugin

FinOps agent MCP: one allocated view of cloud, AI and data costs across providers, shared by your whole team with SSO. Starter $300/mo, 30-day free trial. Powered by [Costory](https://costory.io).

The maintained plugin (MCP connection + skills for Claude Code, Codex, Cursor and Gemini CLI) is [costory-io/costory-finops-mcp-skills](https://github.com/costory-io/costory-finops-mcp-skills).

See [`plugins/costory/README.md`](plugins/costory/README.md) for full documentation.
